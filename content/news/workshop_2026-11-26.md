**When?** Thursday, 26 November 2026, 17:00–20:00.

**Where?** Faculty of Computer and Information Science, Večna pot 113, Ljubljana. Lecture room 3.

**What?**

Get into the flow of AI-assisted development, without leaving good engineering practices behind. This workshop targets beginners and novice vibe coders. We'll kick off with a short introduction to coding harnesses and model options, then dive into a hands-on session using a public repository. Together, we'll implement features on an existing product and explore how clear instructions, useful context, small iterations, code review, and testing help turn AI-generated code into changes you can trust.

**Syllabus:**

1. **Introduction to vibe coding:** AI coding harnesses, model options, and choosing a setup.
2. **Getting to know the product:** a tour of the product we'll be working on.
3. **Hands-on feature development:** building features with AI, scoping tasks, writing instructions, managing context, and keeping changes small.
4. **Review, test, and refine:** inspecting generated code, validating behavior, troubleshooting, and checking for regressions.
5. **Wrap-up:** sharing results, discussing what worked, and capturing practical habits.

Presented by Blaž Pridgar (Data Scientist, Valira AI). Blaž develops computer vision solutions from research to production, covering data engineering, model training, and integration.
